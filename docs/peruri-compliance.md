# Kesesuaian PERURI Chip Hackathon 2026

Diperiksa 8 Oktober 2026 terhadap [halaman resmi](https://summit.peruri.co.id/hackathon), [formulir](https://summit.peruri.co.id/hackathon/register), buku panduan dan template PDF lokal. Batas isi utama enam halaman mengecualikan sampul, daftar pustaka dan lampiran teknis. Formulir menerima PDF hingga 6 MB.

| Ketentuan | Penerapan SENTINEL |
|---|---|
| Mahasiswa aktif, tim hingga empat orang dan dosen pembimbing | Tiga anggota Telkom University; nama pembimbing/contact harus diisi sebelum pengumpulan |
| Struktur buku/template | Ringkasan, latar belakang/rumusan masalah, proposed chip design, referensi, lampiran |
| FAQ menekankan executive summary, problem, proposed chip, technical design, security design | Technical Design dan Security Design diberi subbagian eksplisit di dalam rancangan chip |
| Area Secure Communication dan peningkatan baseline diperbolehkan | Framing, interface integrity, transaksi aman; TT07 CDC FIFO sebagai baseline konsep, vendor Ascon sebagai core |
| Security sebagai fondasi | Threat model, penahanan plaintext, acceptance, replay dan commit ditentukan sebelum integrasi board |
| Hak IP peserta | Kode asli memakai notice hak tim; vendor tetap mengikuti CC0; belum memilih lisensi penggunaan ulang umum |
| Proposal 8 Oktober, finalis 13 Oktober, bootcamp 18–20, summit 21–22 | Rencana persiapan dan exit gate mengikuti tanggal tersebut |

Template menetapkan DE10-Nano; buku menulis DE1-Nano. Rancangan memakai DE10-Nano Cyclone V 5CSEBA6U23I7 sesuai template dan rujukan Terasic; konfirmasi board aktual pada panitia saat integrasi. Formulir memberi label dosen opsional, sedangkan buku/FAQ menyebut pembimbing; tim tetap menyiapkan pembimbing.

Formulir juga memerlukan identitas ketua (termasuk NIM), identitas/email anggota, topik, judul proyek dan persetujuan orisinalitas/privasi. Data pribadi yang belum tersedia tidak dibuat-buat dan tidak dimasukkan ke repositori publik. Pengumpulan tidak dilakukan oleh script ini. Bobot penjurian dan jam penutupan belum ditemukan pada sumber resmi yang diperiksa; tidak dibuat skor peluang menang.
